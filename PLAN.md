# LUMINA — Modular Build Plan

Personal course project (FDE Assignment 1). Isolated from any work account/infra.

## The two objectives
1. **Complete** the assignment: `/evals` passes against a deployed app.
2. **Learn** each subtask — the options, the choice, the "why". Captured in
   [`LEARNINGS.md`](LEARNINGS.md) + inline comments, both feeding the graded
   [`DESIGN.md`](DESIGN.md).

## Architecture (fixed by the assignment — we don't change the contract)
```
Browser ─HTTP+SSE→ Gateway :8787 (public edge) ─→ Agent :8000 (private, holds keys) ─→ Tavily · Google Gemini (chat+embeddings, personal free tier) · MongoDB Atlas
```
- **Gateway** = browser-facing only: CORS, `X-User-Id`→401, zod-validate→400, rate-limit→429,
  SSE pass-through, 502-on-upstream, serve `web/dist`. **Holds no provider key.**
- **Agent** = the AI work: loop, tools, memory, RAG, deep search, jobs worker, run logs.
  **Only** key-holder; **only** enforcer of the deep-search daily cap.
- **One Atlas DB**: 10 collections (`threads, messages, memories, spaces, documents, chunks,
  searchCache, jobs, requests, runs`) + GridFS uploads + 3 search indexes (2 vector, 1 text).

## Working loop (per module)
`plan → build → verify → learn`. Verify with the assignment's own checks
(`curl -N`, `node benchmark/bench.mjs`, `node quality/check.mjs .`). "Learn" = a `LEARNINGS.md`
entry + inline comments at each real decision. Pause-and-teach at 🔴/Teach rows.

## The four rules that decide the grade (never violate)
1. **Grounded or nothing** — every `[n]` resolves to something retrieved *in that request*.
2. **Fail loud** — a provider exception → `502` + `terminated:"error"`; never a plausible fake answer.
3. **Bounded & honest** — caps per gear; a capped run reports `terminated:"cap"`, never `done`.
4. **Evidence over vibes** — every graded number comes from a real run against the deployed app.

## Red lines (automatic fail)
No fabricated citation · no `2xx` on a provider exception · a capped run reported as `done` ·
`plan_research` called from a quick search · editing `web/ packages/contract/ benchmark/ eval/
quality/ scripts/` · any secret reachable from the browser · agent service publicly reachable.
